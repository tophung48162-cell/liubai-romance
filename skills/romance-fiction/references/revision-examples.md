# 改写校准

以下是局部示例，不是完整情节，也不要求每个场景都使用雨、钟表或杯子。

## 从机械问答改为场景段落

避免连续独立段落中的“你今天走？”“票改了。”“为什么？”“还有事。”

可改为：

> 　　她把改签信息发给同事，手机又跳出催交材料的消息。陈叙提着桶站在门边，问她是不是还赶晚上的车。她没有抬头，只把原来的车次划掉，重新核对到站时间。他看过屏幕，便将已经收进袋里的工具倒出来，摆回窗台；她这才放下手机，伸手接住滚到边缘的螺丝。

关键是两人的选择互相影响，回应通过做事发生。不能仅把四句短对白放进同一段。

## 从情绪标签改为物件变化

避免“她感到无比悲伤，终于意识到自己还爱着他”；也避免“她拿起两只碗，又收回一只，这象征她无法接受失去”。

可改为：

> 　　她盛好两碗饭，把第二双筷子摆在桌上，才看见对面的椅子已经推回墙边。她将筷子收进抽屉，饭却没有倒回锅里。等收拾厨房时，碗沿结了一圈薄皮，她添了一点热水，盖好，放进冰箱。

不再补一句“她舍不得”。动作应和人物处境一致，也允许读者保留自己的解释。

## 用人物习惯分声，不人人抖机灵

同一件“饭凉了”的事，可按身份、关系安排不同回应：

- 外出工作的主角：“我这边还得十分钟，你先吃，别等了。”
- 话少、习惯做事的主角：看一眼时间，把锅重新放上火，等电话里的人说完再问：“要不要留一碗？”
- 长辈：把盖子盖回去，催人先坐下，说忙归忙，饭总得吃。

方言在核实后加入符合人物的词汇和语序，不把普通话随机改成几个方言字。地域同时体现在空间、声音、饭菜和生活方式里。

## 让外部变化推一下感情

可采用这样的因果：约定受阻 → 共同解决 → 显露习惯 → 一方误读 → 新证据改变原判断 → 当面改变相处方式。这是可选思路，不是每篇的固定事件表。

维修本身不是心动；一方发现对方忙乱中仍给自己留出干燥的落脚处，随后主动让对方留下吃饭，才有关系推进。揭开误会也不等于和解；需要说清安排，或者在有代价的选择上承担责任。

不在场景后写“他们更靠近了一步”，让下一场的态度、位置和行动呈现变化。

## 总—分—总不露模板痕迹

开头给出矛盾和代价，中间展开选择，结尾再次碰到同一问题，用不同的行动处理。可回到同一扇门、同一个电话或同一件物品，不必重复开头句子。

结尾不写“他们终于学会了沟通，明白爱情需要理解”。可以让原先各自决定的两人，将时间表放在同一张桌上；未来日期仍空着，确定的那一天却由两人一起写下。这个例子不是每篇必用的象征。
