# 言情小说写作

## 开篇

**先用第一句抓住读者，再以具体处境建立感情主线。**

本 Skill 汇集本用户在反复修订中确认的偏好，不把它们视为所有言情小说的通则。默认创作五千字左右的中文短篇言情小说，以虐恋为基调，细节具体，场景鲜明，语言克制。用户的新要求优先，已确认的要求在后续修改中持续有效；此前的苏州、钟表店、旧房、林晚、陈叙和风铃仅为示例，不是必用设定。

开写前在内部确定两人的眼前目标、现实限制、需要付出的代价，以及迫使他们接触的事件。男女主在性格、身份或价值观上有明显对立，这种对立必须影响选择和相处，不能仅靠“冷淡与活泼”的标签。确定少量核心物件、初始状态、后续变化和待回收的伏笔；不必先向用户展示提纲。

第一故事句就抛出有代价的冲突、悬念或强烈反差。不要先铺天气、城市背景或人物履历。紧接着用生活细节建立代入感：请假期限、没接到的电话、冷掉的饭、签不下去的合同等，让读者迅速站到主要视角人物身边。细节必须贴合人物，不通过堆砌苦难索取同情。

全篇采用隐性的“总—分—总”架构：开篇确立关系问题，中段以场景展开选择，结尾回应这个问题。Skill 的“开篇、中段、结尾”是写作指导的三个部分，小说正文不显示这些标签，不用“一、二、三”或章节编号分割文章。

选定稳定的地域、年代、叙述视角和语言节奏。通过屋内空间、作息、买菜吃饭、物品称呼等形成独特风格，而不是堆陌生比喻、华丽辞藻或重复句式。需要方言时按角色的年龄、经历和场合分配；对不熟悉的真实地域和方言先核实可靠资料，必要说明放在正文之外。

**开篇检查：**第一句是否已产生冲突或悬念？虐恋基调是否落到现实代价上？读者是否知道主角眼前要办什么、被什么阻碍？人物对立和伏笔是否已自然进入场景？

## 中段

**沿着相遇或重逢、心动、误会、和解推进，每场都改变关系。**

主线清晰，冲突集中。外部事件为感情服务，不让房屋交易、职场流程、家族秘密变成另一篇故事。删掉某场景若不影响相互认识、亲近、受伤或重新选择，就应压缩或删除。相遇带来接触，心动有行为证据，误会触及真实差异，和解包含承担、表达或安排上的改变，不以作者一句结论代替过程。

持续加压：小冲突、期限逼近、新信息和局面反转不断改变人物的选择、信任和距离。上一场的选择造成下一场压力，不把张力全留给结尾的一场事故，也不每段制造惊天秘密。不靠巧合、强行扣留信息或反复偷听半句话制造误会。虐恋来自想靠近却做错、来不及或必须取舍，不靠反复羞辱、虐待、突然增加绝症；也不要把所有问题归为一个无关紧要的误会。

伏笔第一次出现时就有当下用途，后续再产生另一层意义。通过行动、发现或后果回收，不宣布“原来这就是伏笔”。保持时间、物件位置、谁知道什么及何时知道的一致性，不为反转改写前文事实。

**以物言情，避免情绪直述。** 选择少量与生活和关系相关的物件，用保留、使用、损坏、修复、交还、摆放等变化承接情绪。不写“他心中一震”“她感到无比悲伤”“她终于释然”，也不在动作后解释同一情绪。杯子停在半空、反复抚平折角、第二只碗收回柜子、装好的东西又取出来，都必须有现场缘由；不能人人一难过就捏杯子。物件保留实际功能，不每次出现都赋予哲理，不用密集的眼泪、握拳和颤抖替代刻画。

**让环境参与人物行动。** 空间布局、光线、声音、气味、天气和手边物品要影响人物如何走、看、停、接近或避开，而不是在对白之间插入风景段。细节有辨识度，避免反复靠雨声、昏黄灯光、心跳和沉默制造相同气氛。

**对白口语化且有区分度。** 主角、长辈、同事、中介不能共用一个腔调。根据身份、经历和关系安排说话习惯：有人先说结论，有人绕着具体事说，有人应付生人流利，对亲近的人却说不全。普通对白可以平淡、重复、未说完整，不句句妙语连珠，不像心理咨询师、评论家或作者代言人。方言适量、可从情境理解，不人人满口方言，不混用地区词汇，不让每句方言都承担俏皮效果。

**按场景组织段落。** 不通篇一问一答，不一句话就另起一段，不把短问答简单粘成大段。对白与动作、观察、物件变化共同构成自然段。回应可以通过继续做事、换话题、停顿或延后表达发生；关键问题不能为拖情节永远不答。删除只承担“嗯”“哦”“好”“没有”“为什么”的机械往返，保留短答时赋予情境分量。换说话人时保持可辨认，不为减少段落把多人发言混成一团。

减少“某月某日：某人做了某事”式记录和一句一个时间点的流水账。关键变化用场景展开，次要时间跨度自然嵌入叙述，不把相遇、心动、误会和和解缩成概述。

**中段检查：**人物是否在做选择，选择是否改变感情？压力和反转是否有前因？是否仍有无关支线、直说情绪、解释象征、短句接龙或机械问答？地域、方言和人物声音是否一致而有区别？

## 结尾

**回应开篇的关系问题，以变化后的行动或物件收束，留有余味。**

结尾可以是释然的转身、恰到好处的重逢，或继续交往但未解决全部现实困难，不强求大团圆。回到开篇的场景、问题或核心物件，让读者看见人物如何以不同的方式处理同一件事。主要冲突须有必要交代，不能用含糊代替收束，也不能靠婚礼或突然幸福多年证明和解成功。

不写“他们终于学会了沟通”“爱情需要理解”之类作者总结，不解释物件象征，不以人生哲理作为结论。可以保留未确定的未来，但最后的动作、位置、话语或物件状态应让读者看见关系已经发生的变化。

交付时默认直接给正文，避免长篇解释方法。五千字左右按中文正文篇幅理解，通常以约 4500—5500 字作为工作区间，不含标题和说明；用户另有口径时遵从。不把小段示范冒充完整五千字小说，不虚报精确字数。

小说正文每个自然段开头放两个全角空格：`　　`。标题居中且只出现一次，不作为首行缩进的正文段。聊天环境支持 HTML 时可用 `<div align="center">《标题》</div>`；不支持时采用实际可用的居中方式或说明限制。文档使用真正的段落居中和首行缩进，不用空格伪造样式。

用户指定局部时就地改该段，保留人物、时序和衔接；要求全篇统一或通篇纠偏时整合全文，不不断追加互相冲突的替代片段。不索要用户已给出的偏好，不因最新一项修改而丢掉前面确认的要求。

**结尾与全篇检查：**结尾是否回应开篇且不说教？是否回收关键伏笔？是否以物件和行动承接情绪？全篇是否仍有一句一段、问答对打、时间清单或角色同腔？字数、标题居中、正文两字缩进是否满足要求？
